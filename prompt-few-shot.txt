You are analyzing the names of Telegram channels for geographic references in two steps:

Step 1 – Extract every part of the chat name that refers to a place:
- a name of a country, region, city or city district
- an abbreviation of a place (e.g. "HH", "NRW", "ZH")
- a postal code
- a flag emoji, or another emoji only if it clearly stands for one specific place
Copy each reference exactly as it is written in the chat name.

Step 2 – Interpret the extracted references by determining the place it refers to. Fill in the finest level the reference supports and the levels above it:
- city or district → city, its region and its country (a district is assigned to its city, e.g. "Altona" → city "Hamburg")
- region → region and country; city stays null
- country or country flag → country only
- postal code → the city, region and country it belongs to
- abbreviation → expand it first, then interpret it like the full name
- group of countries (e.g. "DACH") → list its countries if there are only a few; otherwise leave country null and name the group in "Comment"
Write countries, regions and cities with their standard German names. "Region" means the first administrative level below the country (e.g. German state, Austrian state, Swiss canton). List each place only once.

Ambiguity. Set "Confidence" to "Ambiguous" if there is any doubt in either step, for example:
- the word may not be meant geographically (e.g. "Hamburger" as food, "Essen" as the verb "to eat")
- the place name exists more than once (e.g. "Frankfurt", "Georgia")
- the abbreviation or postal code could mean several things (e.g. "B", "M", "1010")
- the reference is vague (e.g. "Süd", "Ostblock")
When it is "Ambiguous", fill in the most likely interpretation and explain the doubt in "Comment".

"Contains_Geo_Reference":
- "Yes": at least one reference was extracted in step 1, even if it is doubtful. Express any doubt through "Confidence".
- "No": nothing in the name could refer to a place. Then all reference fields are null, "Reference_Type" is null and "Confidence" is "Unambiguous".

"Reference_Type":
- "Text" for written place names and words derived from them
- "Abbreviation", "Postal Code" or "Emoji" for those kinds of reference
- "Multiple" when the references are of more than one type
- "Undefined" for a reference that fits none of these
- null when there is no reference

"Comment": one short sentence, or an empty string if there is nothing to note.
